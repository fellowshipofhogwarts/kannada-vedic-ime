Kannada Vedic IME 0.5.0 - quick start (Windows)

1. Install the font: double-click Arkavathi.ttf, then click Install.
   (If you had "Kaveri" or "Kannada Vedic Long" before, uninstall it first:
   Settings > Personalization > Fonts. Arkavathi is the new name of Kaveri.)
2. Double-click kannada_ime.exe. A saffron tray icon with the letter ka appears
   near the clock (click the ^ arrow if you do not see it).
3. Open a text box in a browser, Word or VS Code and choose the font "Arkavathi".
4. Type:  namaste   Siva   ka_   agni'mILE'   c`H   g`M'   jQa   zha   2026
   Ctrl+Shift+K switches Kannada typing on and off. Right-click the tray icon for the menu:
   "Vedic mode" turns the accent keys on or off, "Kannada digits" switches the number keys
   between ೧ ೨ ೩ and 1 2 3, and "Check for updates" opens the release page.

New in 0.5.0: Z = ಽ, :h = ೱ, :H = ೲ, zh = ೞ, :l = ಌ, :L = ೡ, :M = ಁ, and Q after a
consonant = nukta (jQa = ಜ಼). The number keys now type Kannada digits (switch in the tray menu).

Windows may say "Windows protected your PC" because the program is not signed.
Click "More info", then "Run anyway". Only do this for a copy you downloaded from the
official project page.

Notepad does not position Vedic marks correctly; use a browser, Word, LibreOffice or VS Code.

German keyboard: Shift + the key left of Backspace (the accent key) is the break key, no Space needed.
AltGr characters such as ~ work too.

To start it with Windows: press Win+R, type shell:startup, press Enter, and drop a
shortcut to kannada_ime.exe into that folder.

Privacy: no data is collected. The only network call is the optional update check to
GitHub, which you can switch off in the tray menu.
