# Fonts

`Arkavathi.ttf` (version 1.3) is a modified copy of **Goda** 1.0.5 (Parankusacar Institute of Vedic
Studies, derived from Sampige by the Indian Institute of Science). It is licensed under the
**SIL Open Font License 1.1** (`OFL.txt`), not under the MIT / Apache-2.0 licence of the program code.

* Do not call a modified version "Goda" (Reserved Font Name).
* Keep `OFL.txt` with the font when you share it.
* It was called "Kaveri" up to 0.4.0. If you installed Kaveri, uninstall it first
  (Windows: Settings > Personalization > Fonts > Kaveri > Uninstall) and then install Arkavathi.
* Rebuild it from the original Goda with `python3 tools/make_long_marks.py Goda.ttf Arkavathi.ttf`.
